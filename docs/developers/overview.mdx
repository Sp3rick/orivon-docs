This is the home of the Orivon developer documentation. It is written for the
people who build on Orivon: module authors, application developers, integration
engineers, tool builders and everyone who wants to extend the ecosystem. The
goal is to take you from first project to production quality, with practical
examples at every step.

## Who this documentation is for

<CardGrid columns={2}>
  <Card title="Module authors" to="/docs/developers/building-your-first-module">
    Build modules that extend the runtime with new capabilities.
  </Card>
  <Card title="Application developers" to="/docs/developers/building-your-first-application">
    Build applications that run inside the Orivon browser.
  </Card>
  <Card title="Integration engineers" to="/docs/developers/permissions">
    Connect Orivon to wallets, identities, storage and networks.
  </Card>
  <Card title="Tool builders" to="/docs/developers/cli">
    Build developer tools, providers and services on the ecosystem.
  </Card>
</CardGrid>

No prior Orivon experience is required. Some pages assume basic familiarity
with web development, but every concept is introduced where it is first used.

## How to get started

The fastest path is the Quick Start, which gets a project running in minutes:

<Steps>
  <Step title="Install">
    Install the Orivon CLI and SDK. See
    [Installation](/docs/developers/installation).
  </Step>
  <Step title="Create">
    Scaffold a project. See
    [Quick Start](/docs/developers/quick-start).
  </Step>
  <Step title="Build">
    Write your first module or application.
    See [Your First Module](/docs/developers/building-your-first-module).
  </Step>
  <Step title="Run">
    Run, test and debug what you built. See
    [Testing](/docs/developers/testing) and
    [Debugging](/docs/developers/debugging).
  </Step>
</Steps>

If you prefer to learn by doing, start with the
[examples](/docs/developers/examples) or one of the
[tutorials](/docs/developers/tutorials).

## Latest SDK versions

| Package | Version | Status |
| --- | --- | --- |
| `@orivon/sdk` | 0.1.0 | Prerelease |
| `@orivon/cli` | 0.1.0 | Prerelease |
| `orivon-runtime` (Rust) | 0.1.0 | Prerelease |

All packages are at version 0.1.0 and follow the specification drafts described
in the [Standards](/docs/standards) section. The [Migration Guides](/docs/developers/migration-guides)
explain how future releases will be handled.

<Callout type="warning" title="Prerelease software">
  The SDK and CLI are prerelease. Interfaces may change between versions, and
  breaking changes will follow the [versioning](/docs/standards/versioning)
  rules of the specification drafts.
</Callout>
