The fastest way to learn a system is to read working code. This page collects
complete, runnable Orivon examples. Each example is a small project you can
clone, build and run, annotated to show the decisions behind it.

<Callout type="success" title="Get the examples">
  All examples ship with the SDK in the `examples/` directory. Run
  `orivon run examples/hello-world` to try the first one.
</Callout>

## How to use the examples

Each example follows the same shape:

<Diagram caption="From example to running package.">
  <Flow column>
    <DiagramNode accent>Read the project structure</DiagramNode>
    <FlowArrowDown />
    <DiagramNode>Build with `orivon build`</DiagramNode>
    <FlowArrowDown />
    <DiagramNode>Run with `orivon run`</DiagramNode>
    <FlowArrowDown />
    <DiagramNode dim>Change something and rebuild</DiagramNode>
  </Flow>
</Diagram>

The recommended way to learn is to read the example, then modify it. Breaking
something deliberately and fixing it is the strongest kind of practice.

| Example | Covers |
