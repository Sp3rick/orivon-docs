A storage provider stores content for users and serves it back by address.
This example implements a provider with the storage services: putting,
getting, and verifying content by its address.

## Project structure

```text
storage-provider/
  orivon.toml
  src/
    provider.ts
    index.ts
```

## The manifest

```toml
[package]
name = "storage-provider"
version = "0.1.0"
description = "Pins and serves content by address"

[interface]
methods = ["put", "get", "pin", "delete"]

[permissions]
storage = ["write", "read"]
network = ["advertise"]
```

The provider writes and reads storage, and advertises its service on the
network so users can find it. See
[Storage APIs](/docs/developers/storage-apis).

## The implementation

```ts
export async function put(input: {blob: Uint8Array}) {
  const address = await app.storage.put(input.blob);
  await app.storage.pin(address);
  return {address};
}

export async function get(input: {address: string}) {
  return {blob: await app.storage.get(input.address)};
}

export async function deleteBlob(input: {address: string}) {
  await app.storage.unpin(input.address);
  return {status: 'unpinned'};
}
```

`put` returns an address derived from the content. The same content always
has the same address, which is what makes it possible to verify that what you
get is what was stored.

## Verifying integrity

Addresses let the provider prove it stored exactly what was given:

```ts
export async function verify(input: {address: string}) {
  const blob = await app.storage.get(input.address);
  const recomputed = await app.storage.addressOf(blob);
  return {verified: recomputed === input.address};
}
```

If `verified` is false, the content was corrupted or swapped. Content
addressing makes this check cheap and local.

## Advertising the service

The provider lets users find it:

```ts
export function activate() {
  app.network.advertise('storage:provider', '/storage');
}
```

Users resolve `storage:provider` services through the naming system and route
their requests to the provider. See
[Networking APIs](/docs/developers/networking-apis) and
[DNS APIs](/docs/developers/dns-apis).

## What this example teaches

- Content addressing is the storage model: address equals content.
- Providers pin content and serve it; users pay for capacity.
- Providers advertise so the network can route to them.
