*Orivon Research Group · Status: Concept*

This area explores how AI can improve the platform while preserving its
principles — user ownership and privacy. All items are concepts under study,
not shipped features.

## Design constraints

AI features must respect the platform's invariants:

1. **Local by default** — inference runs on-device where possible.
2. **User-controlled** — AI actions are visible and revocable.
3. **Private** — prompts and data do not leave the device without consent.
4. **Non-surveillant** — no data collection for model training by default.

| Concept | Description |

| Translation | Privacy-preserving on-device translation. |
| Search assistance | Semantic query understanding. |

## Developer assistance

| Concept | Description |
| --- | --- |
| Code generation | Suggest module code from intent. |

## Local AI execution

| Topic | Direction |
| --- | --- |
| On-device models | Models that fit device memory and compute. |
| WASM inference | Models running inside the WASM sandbox. |
| Model distribution | Signed, content-addressed model artifacts. |
| Hardware acceleration | GPU/NPU backends where present. |

## Privacy-preserving AI

| Topic | Question |
| --- | --- |
| Differential privacy | Aggregate learning without individual data. |
| Federated learning | Improve shared models without centralizing data. |
| ZK-inference | Prove a result without revealing the input. |
| On-device personalization | Personalize without sending data. |
