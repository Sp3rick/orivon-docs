*Orivon Research Group · Performance Engineering · Status: Active Research*

This area tracks performance as a security and usability property: fast
platforms are safer and more usable. It records optimization work, the
benchmarking methodology, and open performance questions.

## Performance principles

1. **Latency is a feature.** Interactive operations have hard budgets.
2. **Memory is a security budget.** Unbounded memory is a DoS vector.
3. **Measure before optimizing.** Benchmarks are public and reproducible.
4. **Progress bars are the last resort.** Reduce perceived cost, not only real
   cost.
