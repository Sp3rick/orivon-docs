*Orivon Research Group · Status: Concept*

This area explores the future of computing beyond client–server: applications
that are distributed by architecture rather than centralized by accident.
Items here are concepts and research directions, not commitments.

## Distributed applications

| Concept | Description |
| --- | --- |
| Local-first apps | Correct offline, sync optional. |
| Data-locality apps | Data where the user is. |
| Composable apps | Modules that interoperate on-device. |
| Collaborative apps | CRDT-based, no server required. |

## Peer-to-peer systems

The platform's networking and storage already use P2P patterns (see
[Networking Research](/docs/research/networking-research) and
[Storage Research](/docs/research/storage-research)).

| Research topic | Question |
| --- | --- |
| Browsers as peers | Can the browser contribute capacity? |
| Incentives | What motivates peer participation? |
| Trust | How to route and serve without central trust? |

## Edge computing

| Topic | Direction |
| --- | --- |
| Local inference | Run models on-device (see [AI](/docs/research/artificial-intelligence)). |
| Device mesh | Cooperating local devices. |
| Offload | Computation shared across trusted devices. |
| Censorship resistance | Serving without centralized infrastructure. |

## Distributed execution

| Model | Question |
| --- | --- |
| Verifiable execution | Can remote execution be proven correct? |
| Secret sharing | Splitting computation across trust domains. |
| Leaderless apps | Consensus-free collaboration. |
| Migrating state | Moving application state between devices. |

## Future computing models

| Model | Description | Maturity |
| --- | --- | --- |
| Device-centric computing | The device is the primary runtime. | Research. |
| Participatory infrastructure | Users contribute resources. | Research. |
| Privacy-first cloud | Computation on encrypted data. | Research. |
| Autonomous agents | Self-directed software on user-owned infrastructure. | Concept. |
