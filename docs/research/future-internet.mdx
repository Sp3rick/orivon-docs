*Orivon Research Group · Status: Concept*

This area explores the long-term trajectory of the web and where Orivon fits.
It is deliberately speculative: these are directions worth studying, not
predictions the platform commits to.

## The evolution of browsers

| Era | Center of gravity |
| --- | --- |
| Documents (1990s) | Viewing pages. |
| Applications (2000s) | Running software. |
| Platforms (2010s) | Identity, payments, data. |
| Personal infrastructure (future) | User-owned identity, data, and compute. |

The browser is converging on the role of *personal infrastructure*: the
trusted surface through which a user owns their digital life.

## The future of web applications

| Trend | Implication |
| --- | --- |
| Local-first | Apps work offline and sync explicitly. |
| Data portability | Users move between apps without losing data. |
| Composability | Apps built from verified modules. |
| User-issued permissions | Consent as a first-class protocol concept. |
| Verifiability | Apps attest to what they do. |

## Decentralized infrastructure

| Layer | Decentralization direction |
| --- | --- |
| Naming | User-owned DNS. |
| Networking | P2P and WebTransport. |
| Storage | Distributed storage networks. |
| Identity | Self-sovereign DIDs. |
| Compute | Participatory infrastructure. |

The shared property is the removal of single points of control and failure.

## Next-generation internet architecture

| Concept | Question |
| --- | --- |
| Content-centric networking | Address content, not hosts. |
| Privacy by architecture | No central observation points. |
| Verifiable provenance | Signed and attested resources. |
| Sovereign identity | Identity that survives providers. |
| Participatory access | Users are infrastructure. |
