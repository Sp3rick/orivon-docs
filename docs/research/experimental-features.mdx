*Orivon Research Group · Status: Experimental / Concept / Proposal*

This page collects ideas that are not yet finalized. They are published for
discussion and research, and are **explicitly not production-ready**. Do not
build on them.

## Status labels

| Label | Meaning |
| --- | --- |
| `Experimental` | Prototype-level; may change or be abandoned. |
| `Concept` | An idea with no implementation commitment. |
| `Research` | Under active investigation. |
| `Proposal` | A proposed direction not yet accepted. |

A label is never stronger than the evidence. Items that survive evaluation
move to the [Design Documents](/docs/research/design-documents) as accepted
decisions; the rest are archived.

## Review process

| Stage | Gate |
| --- | --- |
| Idea | Recorded with a status label. |
| Prototype | Demonstrates the core mechanism. |
| Evaluation | Measured against requirements and trade-offs. |
| Accepted | Recorded in [Design Documents](/docs/research/design-documents). |
| Archived | Rejected or superseded, with rationale. |
