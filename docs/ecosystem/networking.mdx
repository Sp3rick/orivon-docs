Every service in the ecosystem, from naming to storage to payments, depends on a
network layer that connects participants without central servers. This page
explains how that networking works and why it is the infrastructure that makes
decentralization real.

## Why networking is a first class layer

On the classic web, "the network" is invisible plumbing that happens to be
controlled by a small number of providers. For the ecosystem, connectivity is a
core service, because the whole promise of the system, that no single party
controls access, depends on it.

## From client server to a mesh

The classic model is a hub and spoke: everyone connects to a few servers. The
ecosystem's model is a mesh: participants connect to each other directly, and
content and records travel through the network instead of being served from a
center.

This is not an all or nothing switch. The ecosystem works in both modes: classic
client server traffic keeps working, and peer to peer traffic adds resilience
where it is available.

## How the network layer works

The networking layer provides three things on top of ordinary internet
connections:

1. **Discovery.** Finding peers and services by identity and name, without
   central directories.
2. **Transport.** Moving data directly between participants, with fallbacks when
   direct connections are blocked (for example, behind strict firewalls).
3. **Addressing.** Connecting the [Naming System](/docs/ecosystem/naming-system)
   to live, reachable services.

## Who runs the network

The network is run by its participants. Anyone can contribute capacity: storage,
relaying and discovery. These contributions are part of the ecosystem's
economy and are discussed under [Governance](/docs/ecosystem/governance) and the
planned [Orivon Foundation](/docs/ecosystem/future-products).

<Callout type="info" title="Did you know?">
  Because integrity comes from content addressing, the same data can be served
  by any number of peers. This is what makes the ecosystem resilient: there is
  no single copy to delete.
</Callout>

## Networking and the Web3 Score

How a site is hosted shows up in its [Web3 Score](/docs/ecosystem/web3-score).
A site that runs on decentralized infrastructure scores higher on the
decentralization dimension than one that depends on a single server, which gives
developers a concrete incentive to use the network layer.
