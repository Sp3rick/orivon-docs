This page lists all **first-party** open-source licenses used by Orivon
repositories. For third-party dependencies, see [Third-Party Licenses](/docs/project/third-party-licenses).

## License summary

| License | Repositories | Components |
| --- | --- | --- |
| **Apache License 2.0** | All platform repositories | Runtime, Browser, Core, SDKs, CLI, Modules |
| **CC BY 4.0** | `orivon-docs`, `orivon-brand`, `orivon-research` | Documentation, Brand assets, Whitepapers |
| **MIT** | `orivon-templates`, `orivon-ci` | Project templates, CI configs |
| **CC0 1.0** | `orivon-test-vectors` | Cryptographic test vectors, conformance data |

## License compatibility matrix

| License | Compatible with Apache 2.0? | Can be used in Orivon? |
| --- | --- | --- |
| Apache 2.0 | Yes | Yes (primary) |
| MIT | Yes | Yes (templates, CI) |
| BSD-2/3-Clause | Yes | Yes (if needed) |
| CC BY 4.0 | Yes (for docs/assets) | Yes (docs, brand) |
| CC0 1.0 | Yes | Yes (test data) |
| GPL / AGPL / LGPL | **No** | **Blocked** |
| MPL 2.0 | Yes (with conditions) | Review required |
| EPL 2.0 | Yes (with conditions) | Review required |

<Callout type="warning" title="Copyleft licenses are blocked">
  GPL, AGPL, LGPL, and other copyleft licenses are **not permitted** in
  Orivon platform repositories. They are blocked by automated license scanning
  in CI. Exceptions require TSC approval with a migration plan.
</Callout>
