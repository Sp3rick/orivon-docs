These guidelines ensure Orivon looks and sounds consistent across every
touchpoint — from documentation to swag to partner integrations.

## Logo

### Primary logo
The **Orivon wordmark + symbol** is the primary logo. It represents the
union of technology (symbol) and identity (wordmark).

| Variation | Use Case | Example |
| :--- | :--- | :--- |

| **Black** | Single-color print, fax | ![Black](/logos/orivon-black.svg) |
| **Wordmark only** | Tight horizontal spaces | ![Wordmark](/logos/orivon-wordmark.svg) |

### Clear space
Maintain clear space equal to the **height of the "O" in the wordmark** on
all sides. No other elements (text, images, other logos) may intrude.

```
    ┌─────────────────────────────┐
    │  ↑ clear space (O height)   │
    │  ┌─────────────────────┐    │
    │  │  ORIVON  ◆          │    │
    │  └─────────────────────┘    │
    │  ↓ clear space (O height)   │
    └─────────────────────────────┘
```

### Minimum size

| Format | Minimum Width |
| :--- | :--- |
| **Digital** | 24px (symbol), 120px (wordmark), 160px (full) |
| **Print** | 10mm (symbol), 50mm (wordmark), 60mm (full) |

### Accessibility
All primary color combinations meet **WCAG 2.1 AA** contrast ratios:
- Orivon Blue on White: 4.8:1 ✅
- White on Orivon Blue: 4.8:1 ✅
- Electric Cyan on Deep Navy: 7.2:1 ✅
- Signal Green on Deep Navy: 8.1:1 ✅
- Warning Amber on Deep Navy: 12.4:1 ✅
- Alert Red on White: 5.1:1 ✅

**Do not invent new pairings.** Use the defined combinations.

## Typography

Inter is used for all UI, headings, body text, and code (monospace variant).

Available at: [Google Fonts](https://fonts.google.com/specimen/Inter) | [GitHub](https://github.com/rsms/inter)

| **Medium** | 500 | Emphasis, subheadings |
| **SemiBold** | 600 | Headlines, buttons |

## Voice and Tone

### Voice attributes (always)

| Attribute | Description | Example |
| :--- | :--- | :--- |
| **Clear** | Simple words, short sentences, define jargon | "The runtime loads modules" not "Modules are loaded by the runtime" |
| **Confident** | We know what we're building; no hedging | "Orivon provides..." not "Orivon aims to provide..." |
| **Inclusive** | "You," "we," "the community" — not "the user" | "You can build modules" not "Developers can build modules" |
| **Honest** | Acknowledge trade-offs, risks, what's not built | "This is experimental" not "This works perfectly" |

### Tone by context

| Context | Tone | Example |
| :--- | :--- | :--- |
| **Documentation** | Instructional, precise, encouraging | "Create your first module in 5 minutes" |
| **Blog/Announcements** | Celebratory, transparent, forward-looking | "We're excited to share v1.2..." |
| **Social Media** | Conversational, community-focused, visual | "Just shipped: hot reload for modules! 🚀" |
| **Security/Incidents** | Calm, factual, action-oriented | "We've identified and fixed a sandbox issue..." |
| **Governance** | Neutral, procedural, respectful | "The TSC has ratified the charter..." |
| **Error Messages** | Helpful, specific, actionable | "Module 'crypto' requires network:https capability" |

### Writing principles

<CheckList
  items={[
    'Use active voice. "The runtime loads modules" not "Modules are loaded by the runtime."',
    'Define technical terms on first use.',
    'Prefer "you" over "the user" or "the developer."',
    'Show, don\'t just tell — use code, diagrams, screenshots.',
    'Acknowledge uncertainty: "This is experimental" beats "This works."',
    'One idea per paragraph. One task per section.',
    'Use Oxford comma. Use contractions (it\'s, you\'re, we\'ll).',
    'Avoid: "leverage," "utilize," "facilitate," "enable" — use "use," "help," "let."',
  ]}
/>

## Co-branding (Partners)

For joint materials with partners:

| Rule | Specification |
| :--- | :--- |
| **Placement** | Orivon logo left, partner logo right |
| **Sizing** | Equal visual weight (same height) |
| **Spacing** | Minimum 2x clear space between logos |
| **Alignment** | Horizontal center or baseline |
| **Background** | Sufficient contrast for both logos |
| **Approval** | Partner uses their approved logo only |
