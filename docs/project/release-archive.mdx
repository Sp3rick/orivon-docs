## Verification

Every release includes:
- **Cosign/Sigstore signatures** (keyless, transparency log)
- **SHA256 checksums** (published with release)
- **SBOM** (CycloneDX + SPDX)
- **Provenance attestation** (SLSA Level 3 target)
- **GitHub Attestations** (for npm/crates.io packages)

See [Downloads](/docs/project/downloads#verification) for verification instructions.
