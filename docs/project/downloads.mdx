## Verification

Every release artifact is signed and includes verification metadata:

```bash
# 1. Download artifact + .sig + .crt
wget https://github.com/OrivonBrowser/orivon-browser/releases/download/v1.2.0/orivon-browser-linux-x64.AppImage
wget https://github.com/OrivonBrowser/orivon-browser/releases/download/v1.2.0/orivon-browser-linux-x64.AppImage.sig
wget https://github.com/OrivonBrowser/orivon-browser/releases/download/v1.2.0/orivon-browser-linux-x64.AppImage.crt

# 2. Verify with cosign
cosign verify-blob \
  --signature orivon-browser-linux-x64.AppImage.sig \
  --cert orivon-browser-linux-x64.AppImage.crt \
  orivon-browser-linux-x64.AppImage

# 3. Verify checksum
sha256sum -c orivon-browser-linux-x64.AppImage.sha256
```

### Verification Methods
| Method | Tools | Artifacts |
| :--- | :--- | :--- |
| **Cosign/Sigstore** | `cosign` | All binaries, containers |
| **Checksums (SHA256)** | `sha256sum` | All files |
| **SBOM** | `cosign verify-attestation` | All releases |
| **Provenance** | SLSA verification | All releases |
| **GitHub Attestations** | `gh attestation` | npm/crates.io packages |

- **Mirror request:** infrastructure@orivon.dev
- **Checksum mismatch:** **Do not run** — report to security@orivon.dev immediately
