### Prohibited Use
- **Imply endorsement** — "Official Orivon X" without authorization.
- **Confusing similarity** — Names/logos that could confuse users.
- **Commercial merchandise** — Without written permission.
- **Domain squatting** — `orivon-*`, `orivon.` variants.
- **App store confusion** — Publishing modified browser as "Orivon" without clear differentiation.

## Export Controls

Orivon includes cryptographic functionality. It may be subject to export
controls (EAR, ITAR). The project:
- Uses only publicly available cryptography (RFC standards, NIST curves).
- Does not implement export-restricted algorithms.
- Provides source code publicly (publicly available software exemption).

**Users are responsible** for compliance with their local export laws.
