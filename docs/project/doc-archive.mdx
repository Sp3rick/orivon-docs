## Archive Structure

Each archived version includes:
- Complete documentation site (static HTML)
- PDF export of all pages
- Markdown source (Git tag)
- Search index
- Redirect from old URLs

## Accessing Archives

### Web Archives
```
https://v1.1.docs.orivon.dev/
https://v1.0.docs.orivon.dev/
https://v0.9.docs.orivon.dev/
```

### Git Tags
```bash
# Clone and checkout specific version
git clone https://github.com/OrivonBrowser/orivon-docs.git
cd orivon-docs
git checkout v1.1.0  # or v1.0.0, v0.9.0, etc.
```

## Version Support Policy

| Version | Documentation Support |
| :--- | :--- |
| **Current Stable** | Full updates, corrections, new content |
| **LTS (v1.0)** | Security/critical corrections only |
| **Previous Stable** | No updates (archived as-is) |
| **Beta/Preview** | Not archived (ephemeral) |

## Redirects

Old URLs automatically redirect:
- `/docs/v1.1/...` → `https://v1.1.docs.orivon.dev/...`
- `/docs/v1.0/...` → `https://v1.0.docs.orivon.dev/...`

## Searching Archives

Each archived version has its own search index. Use the versioned site's
search, or search GitHub:
```
site:v1.1.docs.orivon.dev "search term"
repo:OrivonBrowser/orivon-docs "search term" tag:v1.1.0
```

## Contributing to Archived Versions

**Archived versions are read-only.** To fix an error in an archived version:
1. Fix it in the current version (`main` branch).
2. If critical, cherry-pick to the LTS branch (`release/v1.0`).
3. The archive will be regenerated on next release.

## Retention

| Artifact | Retention |
| :--- | :--- |
| **Web Archives** | Indefinite (storage permitting) |
| **Git Tags** | Indefinite |
| **Download Packages** | 3 years, then Git tags only |
| **Search Indices** | Regenerated per version |
