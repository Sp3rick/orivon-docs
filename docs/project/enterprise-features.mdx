This page describes Orivon's enterprise-oriented capabilities, clearly
distinguishing **current features** (shipped in v1.2) from **planned features**
(on the roadmap) and **future initiatives** (research/design phase).

<Callout type="warning" title="No unsupported claims">
  Features marked **Planned** or **Future** are not yet implemented. They
  represent roadmap intent and may change based on community feedback,
  technical discovery, and resource availability.
</Callout>

## Feature status legend

| Badge | Meaning |
| :--- | :--- |
| **✅ Current** | Implemented and shipped in v1.2 (or specified version) |
| **🚧 Planned** | On roadmap with target release; design/implementation in progress |
| **🔬 Future** | Research/design phase; no committed timeline |
| **❌ Not Planned** | Explicitly not on roadmap |

## Security & Isolation

| Feature | Status | Version | Details |
| --- | --- | --- | --- |
| **Capability-based sandbox** | ✅ Current | v1.0 | Per-module, fine-grained, deny-by-default |

| **Policy engine (allowlists)** | ✅ Current | v1.2 | Centralized capability policies |

| **Remote attestation** | 🔬 Future | v2.0+ | TPM/TEE attestation for module integrity |

## Comparison: Current vs. Planned vs. Future

| Category | Current (v1.2) | Planned (v1.3–v1.5) | Future (v2.0+) |

| **Deployment** | Self-hosted registry, updates | Air-gapped, GitOps, fleet API | Multi-region, geo-replication |
| **Observability** | Logs, metrics, tracing | Dashboards, alerts, Grafana | Forensic export |
| **Developer** | Private registry, IDE, CI/CD | Policy-as-code, internal docs | Backstage plugin |
| **Compliance** | SBOM, scanning, licenses | Provenance, regulatory mapping | Data residency, export controls |

## Feature request process

Enterprise needs drive roadmap priorities. To request a feature:

1. **Check roadmap** — [Roadmap](/docs/project/roadmap) and [Enterprise](/docs/project/enterprise).
2. **Open discussion** — Forum `#enterprise` category with use case, requirements, priority.
3. **Engage** — Join Enterprise Working Group (forming) or TSC office hours.
4. **Contribute** — Sponsor development via [Grants Program](/docs/community/grants-program) or [Professional Services](/docs/project/professional-services).

<Callout type="success" title="Your requirements shape the roadmap">
  Enterprise feature requests from organizations evaluating or adopting Orivon
  get priority attention. The community values real-world deployment feedback.
</Callout>
