The **Brand Center** is the single source of truth for Orivon's visual identity
and brand resources. Whether you're a contributor, partner, journalist, or
community member, start here.

## Brand at a glance

| Element | Specification |
| :--- | :--- |
| **Primary Logo** | Wordmark + Symbol (Orivon Blue `#0066FF`) |
| **Primary Color** | Orivon Blue `#0066FF` |
| **Secondary Colors** | Deep Navy `#0A0F1A`, Pure White `#FFFFFF`, Electric Cyan `#00D4FF` |
| **Typography** | Inter (UI, Headings, Body), Inter Mono (Code) |
| **Iconography** | Lucide (outlined, 2px stroke) |
| **Voice** | Clear, Confident, Inclusive, Honest |

## Brand governance

| Question | Answer |
| :--- | :--- |
| **Who owns the brand?** | Orivon Project (to be transferred to Orivon Foundation) |
| **Who approves exceptions?** | Brand Working Group (Community WG) + TSC |
| **Can I modify the logo?** | No — see [Brand Guidelines](/docs/project/brand-guidelines#do-not) |
| **Can I use the logo on merchandise?** | Non-commercial: yes. Commercial: request permission. |
| **Do I need approval for "Built with Orivon"?** | No — use the provided badge from [Logos & Assets](/docs/project/logos-assets) |
| **What if I see misuse?** | Report to brand@orivon.dev |

## Request custom assets

Need a format, size, or variation not in the kits?
Email **brand@orivon.dev** with:
- Use case and context.
- Required formats/sizes.
- Timeline.
- Any brand guideline exceptions needed.

Typical response: 2 business days.
