The Orivon project history traces the evolution from initial concept to the
current platform. This timeline captures the major milestones, technology
decisions, and organizational developments that shaped the project.

<Callout type="info" title="History is a living document">

  milestone. See the [Release Archive](/docs/project/release-archive) for
  detailed release notes and the [Changelog Archive](/docs/project/changelog-archive)
  for comprehensive change records.
</Callout>

## Technology evolution

| Area | 2024 | 2025 | 2026 | 2027+ (Planned) |
| --- | --- | --- | --- | --- |
| **Runtime** | Prototype | Stable v0 | v1.x stable | v2.0: components, async |
| **Browser** | Shell | MVP | Beta | Stable, extensible |
| **SDK** | Rust only | TS + Rust | v1.x stable | Multi-language |
| **Standards** | Drafts | v1 published | v1.x maintenance | Standards track |
| **Governance** | Ad-hoc | TSC formed | Working groups, elections | Foundation |
| **Ecosystem** | None | Early | Directory, grants | Marketplace, marketplace |
| **Compliance** | None | Planning | Gap analysis | SOC 2, ISO |
