How Orivon is funded today, how we plan for long-term sustainability, and
the principles that guide our financial decisions.

<Callout type="info" title="Transparency commitment">
  Orivon does not yet have a formal legal entity (Foundation planned 2027).
  Current funding flows through sponsor organizations directly to contributors.
  This page will evolve with the Foundation. See [Transparency Reports](/docs/project/transparency) for quarterly updates.
</Callout>

## Funding philosophy

| Principle | Practice |
| :--- | :--- |
| **Diversified** | No single source > 50% of budget. Mix of sponsors, grants, services, ecosystem. |
| **Transparent** | Public budget, expenses, sponsor list, grant decisions. |
| **Community-aligned** | Funding follows community priorities (roadmap, grants, infrastructure). |
| **No strings** | Sponsors get visibility, not control. Governance is community-owned. |
| **Sustainable** | Reserves for 12+ months operations; endowment target for Foundation. |

## Expense categories

| Category | Typical % | Examples |
| :--- | :--- | :--- |
| **Infrastructure** | 15–25% | CI/CD, registry, docs hosting, monitoring, domains |
| **Security** | 10–15% | Audits, bug bounties, disclosure coordination, crypto review |
| **Grants Program** | 20–30% | Infrastructure, research, ecosystem, education grants |
| **Community** | 10–15% | Events, meetups, hackathons, swag, travel fund |
| **Documentation** | 5–10% | Docs site, technical writing, translation, research library |
| **Operations** | 10–15% | Legal, accounting, project management, compliance prep |
| **Reserves** | 10%+ | Emergency fund, future initiatives |

## Sustainability model

### Phase 1: Sponsor-Dependent (2024–2026)
- Core team employed by sponsor organizations.
- Infrastructure sponsored (GitHub, Vercel, cloud credits).
- Risk: Concentration in few sponsors.

### Phase 2: Diversified + Foundation (2027–2028)
- Orivon Foundation incorporated (nonprofit).
- Sponsor agreements → Foundation.
- Grants program at scale ($500k+/yr).
- Professional services revenue begins.
- Individual donation platform.

### Phase 3: Self-Sustaining Ecosystem (2029+)
- Marketplace revenue (module transactions, registry fees).
- Professional services marketplace (partner revenue share).
- Endowment income covers core operations.
- Sponsors become optional, not essential.

## Community support

### How the community funds Orivon
| Method | Status | Details |
| :--- | :--- | :--- |
| **Code contributions** | Always | The primary "currency" of the project |
| **Documentation** | Always | Writing, translating, reviewing |
| **Community work** | Always | Events, mentorship, support, advocacy |
| **Grants applications** | Active | Propose funded work via [Grants Program](/docs/community/grants-program) |
| **Bug bounties** | Planned | Security rewards via [Security Policy](/docs/project/security-policy) |
| **GitHub Sponsors** | Planned | For individual maintainers/contributors |
| **Open Collective** | Planned | For project-level recurring donations |

| :--- | :--- | :--- |

## Governance of funds

| Decision | Authority |
| :--- | :--- |
| **Annual budget** | TSC proposes → Foundation Board approves |
| **Grant awards** | Grants Committee (community + TSC + partners) |
| **Sponsor agreements** | Foundation Board (with TSC input on technical impact) |
| **Reserve spending** | Foundation Board (emergency: Executive Director + Chair) |
| **Investment policy** | Foundation Board (conservative, mission-aligned) |

  the next grant. The Foundation structure protects this independence.
