## About Orivon (Boilerplate)

### Short (50 words)
> **Orivon** is an open-source browser and platform that returns control of the web to its users. Built on WebAssembly, capability-based security, and open standards, Orivon enables user-owned identity, private data, and a programmable web where participants are rewarded for the value they create. Licensed Apache 2.0, community-governed.

### Medium (100 words)
> **Orivon** is an open-source browser and platform returning control of the web to its users. Built on WebAssembly, capability-based security, and open standards, Orivon enables user-owned identity (DIDs), private data, and a programmable web where participants are rewarded for the value they create through the Web3 Score reputation layer. The platform includes the Orivon Browser, Orivon Runtime (WASM sandbox), Orivon Core libraries, and Orivon SDKs. Licensed under Apache 2.0 and governed by its community through an Apache-style meritocratic model. No single company controls Orivon.

### Long (200 words)
> **Orivon** is an open-source browser and platform that returns control of the web to its users. Unlike traditional browsers that serve as gatekeepers for platform interests, Orivon is built on a fundamentally different architecture: WebAssembly modules running in a capability-based sandbox, user-owned decentralized identity (DIDs), a portable reputation layer (Web3 Score), and a censorship-resistant naming system.
>
> The platform consists of:
> - **Orivon Browser** — The flagship user agent: private, capable, extensible.
> - **Orivon Runtime** — The WebAssembly runtime with fine-grained capability enforcement.
> - **Orivon Core** — Shared libraries for networking, storage, identity, permissions.
> - **Orivon SDKs** — TypeScript and Rust SDKs for building modules and applications.
> - **Orivon Standards** — Open specifications for module format, capabilities, naming, identity, Web3 Score.
>
> Orivon is licensed under the Apache License 2.0 — permissive, patent-granting, enterprise-friendly. The project is governed by its community through a meritocratic model inspired by the Apache Software Foundation: maintainers own repositories, working groups coordinate cross-cutting topics, and a Technical Steering Committee sets technical direction. No single company or individual controls the project.
>
> The Orivon Foundation (incorporation planned 2027) will serve as the legal and financial steward, holding trademarks, managing funds, and ensuring long-term sustainability — while the community retains technical governance.

## Embargo Policy

- Orivon does not use embargoes for routine releases.
- For major announcements (governance changes, security incidents, major releases), a 24–48 hour embargo may be offered to registered journalists.
- To register for embargoed announcements, email press@orivon.dev with your publication and contact info.
