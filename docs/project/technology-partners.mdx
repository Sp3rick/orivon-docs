Technology Partners are organizations that **integrate Orivon into their
products or platforms** or **build developer tools and infrastructure on
Orivon APIs**.

<Callout type="info" title="Coming Soon">
  No technology partners have been formally announced as of July 2026. This
  page is reserved for future partnerships.
</Callout>

## Technology partner profile

| Attribute | Description |
| :--- | :--- |
| **Integration type** | Embed Orivon Runtime, use Orivon SDKs, extend Orivon Browser |
| **Value to partner** | Differentiated capabilities (WASM sandbox, DID identity, Web3 Score) |
| **Value to Orivon** | Expanded reach, real-world hardening, feedback, co-marketing |
| **Technical liaison** | Dedicated Orivon engineer for integration support |
| **Roadmap input** | Quarterly session to influence relevant roadmap areas |

## Example integration patterns (planned)

| Pattern | Description | Example |
| :--- | :--- | :--- |
| **Embedded Runtime** | Cloud provider offers Orivon Runtime as managed service | "Orivon on AWS/GCP/Azure" |
| **IDE/Editor Plugin** | VS Code, JetBrains, Neovim extensions for module development | "Orivon DevTools" |
| **CI/CD Integration** | GitHub Actions, GitLab, Azure Pipelines, CircleCI orbs | "orivon/action@v1" |
| **Observability** | Datadog, New Relic, Grafana Cloud integrations | "Orivon Dashboard" |
| **Security Tools** | SAST/DAST/SCA vendors adding Orivon support | "Orivon Scanner" |
| **Framework Binding** | React, Vue, Svelte, Solid bindings for Orivon SDK | "orivon-react" |

## Benefits for technology partners

| Benefit | Details |
| :--- | :--- |
| **Early access** | Pre-release SDKs, runtime, browser builds |
| **Technical liaison** | Named Orivon engineer (quarterly sync) |
| **Roadmap input** | Quarterly session; feature requests prioritized |
| **Co-marketing** | Joint blog, webinar, case study, logo placement |
| **Event access** | Speaking slots at Orivon Summit, community events |
| **Support channel** | Dedicated Slack / email for integration issues |
| **Certification** | "Orivon Certified Integration" badge (planned) |

## Requirements

| Requirement | Details |
| :--- | :--- |
| **Standards compliance** | Use published Orivon APIs/specs; no private APIs |
| **Version tracking** | Declare supported Orivon versions; test matrix |
| **Security coordination** | Participate in disclosure; patch within SLA |
| **Public listing** | Logo, description, integration type in partner directory |
| **Annual review** | Mutual value assessment; renew or graduate |

## How to apply

**Email:** partnerships@orivon.dev

Include:
- Organization and product description.
- Proposed integration pattern.
- Technical scope and timeline.
- Mutual value hypothesis.
- Technical contact.

## Related programs

| Program | Relationship |
| :--- | :--- |
| **Integration Partners** | Connect external systems TO Orivon |
| **Professional Services Partners** | Deliver services ON Orivon |
| **Ecosystem Partners** | Build applications FOR Orivon users |
| **Grants Program** | Fund open-source integrations |

<Callout type="success" title="Build on the platform, not around it">
  Technology partners use Orivon's open APIs and standards — no reverse
  engineering, no fragile hacks. The platform is designed to be integrated.
</Callout>
