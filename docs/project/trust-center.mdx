## Security posture

### Principles
- **Capability-based security** — No ambient authority; every action requires an explicit capability.
- **Defense in depth** — Sandbox, capability enforcement, code review, fuzzing, formal verification.
- **Secure by default** — Permissions denied unless explicitly granted; no telemetry by default.
- **Supply chain integrity** — Signed releases, SBOMs, dependency scanning, provenance attestation.
- **Transparent disclosure** — Coordinated vulnerability disclosure with public advisories.

### Current capabilities
| Capability | Implementation | Verification |
| --- | --- | --- |
| **WASM sandbox** | Capability-based, per-module | Unit tests, fuzzing, audit |
| **Memory safety** | Rust core, WASM isolation | Clippy, Miri, sanitizers |
| **Cryptography** | Ring, aws-lc-rs, vetted primitives | Crypto review, test vectors |
| **Dependency scanning** | Cargo audit, npm audit, OSV | CI on every PR |
| **Signed releases** | Cosign/Sigstore, keyless signing | `cosign verify` on all artifacts |
| **SBOM generation** | CycloneDX JSON/SPD | Published with every release |

## Privacy posture

### Principles
- **Local-first** — Data stays on device unless user explicitly shares.
- **No telemetry by default** — Opt-in only; transparent about what is collected.
- **User-controlled identity** — DIDs, keys, credentials owned by user.
- **Minimal data** — Collect only what is necessary for requested functionality.
- **Transparency** — Public privacy policy; open-source code auditable.

### Data handling
| Data Type | Collection | Purpose | Retention |
| --- | --- | --- | --- |
| **Crash reports** | Opt-in | Stability improvement | 90 days |
| **Performance metrics** | Opt-in | Performance optimization | 90 days |
| **Usage analytics** | Not collected | — | — |
| **Identity credentials** | User-controlled | User authentication | User-controlled |
| **Web3 Score signals** | User-consented | Reputation computation | User-controlled |

## Responsible disclosure

Orivon operates a **Coordinated Vulnerability Disclosure (CVD)** program:

- **Scope:** All Orivon repositories and infrastructure.
- **Safe harbor:** Good-faith research protected; no legal action for compliant disclosure.
- **Response:** Acknowledgment within 48 hours; triage within 5 business days.
- **Coordination:** Private fix development; public advisory on release.
- **Recognition:** Hall of fame; swag; grant consideration for significant findings.

**Report to:** security@orivon.dev (PGP key available)

See [Responsible Disclosure](/docs/contributors/responsible-disclosure) for full
process, scope, and rewards.
