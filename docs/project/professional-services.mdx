Orivon's professional services ecosystem is being designed for launch in
2027. This page describes the planned service categories, delivery models,
and how to engage.

<Callout type="info" title="Coming Soon — Planned for 2027">
  Professional services are not yet available. This page documents the
  planned framework. Organizations interested in early access should contact
  enterprise@orivon.dev.
</Callout>

## Service categories

### 1. Architecture & Strategy Consulting
| Service | Description | Target Audience |
| :--- | :--- | :--- |
| **Enterprise Architecture Review** | Assess fit, design deployment model, identify gaps | CTO, Platform Architects |
| **Threat Modeling Workshop** | STRIDE-based threat model for your deployment | Security Teams |
| **Compliance Gap Analysis** | Map Orivon capabilities to your regulatory requirements | Compliance, Legal |
| **Migration Planning** | From legacy browser/platform to Orivon | Engineering Leads |
| **Policy Design** | Capability policies, module allowlists, identity integration | Platform Teams |

### 2. Implementation Services
| Service | Description | Deliverables |
| :--- | :--- | :--- |
| **Registry Deployment** | Deploy and configure internal module registry | Running registry, docs, runbooks |
| **Policy Engine Setup** | OPA deployment, policy authoring, CI/CD integration | Policy repo, test suite, GitOps pipeline |
| **Identity Integration** | OIDC/SAML/SCIM with Entra ID, Okta, Keycloak | Working auth flow, provisioning |
| **Observability Stack** | Prometheus/Grafana/Loki/Tempo with Orivon dashboards | Dashboards, alerts, runbooks |
| **Air-Gapped Deployment** | Prepare and deploy air-gap bundle | Deployed environment, update process |
| **Custom Module Development** | Build internal modules for your use cases | Module source, tests, documentation |

### 3. Training & Enablement
| Service | Format | Audience |
| :--- | :--- | :--- |
| **Orivon Fundamentals** | 2-day workshop (virtual/on-site) | Developers, Platform Engineers |
| **Module Development** | 3-day hands-on workshop | Developers |
| **Enterprise Deployment** | 2-day workshop + lab | Platform/DevOps Engineers |
| **Security & Policy** | 1-day deep dive | Security Engineers |
| **Train-the-Trainer** | 3-day certification | Internal Champions |
| **Executive Briefing** | 2-hour session | Leadership, Decision Makers |

### 4. Ongoing Support Packages (Planned)
| Tier | SLA | Includes | Target |
| :--- | :--- | :--- | :--- |
| **Community** | Best-effort (Discord/Forum) | — | Free |
| **Standard** | Business hours, 24h response | Triage, workaround, upgrade guidance | 2027-H1 |
| **Professional** | 24/7, 4h response | Dedicated Slack, quarterly reviews, security advisories | 2027-H2 |
| **Premium** | 24/7, 1h response | Named TAM, custom runbooks, joint roadmap planning | 2028 |

## Delivery models

| Model | Description | Best For |
| :--- | :--- | :--- |
| **Project-based** | Fixed scope, timeline, deliverables | One-time implementations |
| **Retainer** | Monthly hours, flexible scope | Ongoing platform evolution |
| **Embedded** | Engineer(s) join your team | Deep integration, knowledge transfer |
| **Workshop** | Fixed curriculum, hands-on | Team enablement |
| **Advisory** | Part-time architect access | Strategic guidance |

## Partner ecosystem

Professional services will be delivered by:
- **Orivon Core Team** (limited capacity, strategic engagements)
- **Certified Partners** (trained, vetted, listed in [Partner Directory](/docs/project/partners))
- **Community Experts** (recognized contributors, listed in [Community Showcase](/docs/community/community-showcase))

### Partner certification (planned)
1. **Technical assessment** — Architecture, module dev, deployment.
2. **Case study** — Documented successful deployment.
3. **Reference check** — Customer validation.
4. **Annual renewal** — Continued competency.

## Pricing philosophy

| Principle | Practice |
| :--- | :--- |
| **Transparent** | Public price list (when launched) |
| **Value-based** | Priced on outcomes, not hours |
| **No vendor lock-in** | All deliverables are yours (open source) |
| **Community discount** | Active contributors get reduced rates |
| **Non-profit/academic** | Significant discounts for public good |

## Engagement process

<Steps>
  <Step title="Inquiry">
    Email enterprise@orivon.dev with: organization, use case, timeline, budget range.
  </Step>
  <Step title="Discovery">
    60-min call: architecture, requirements, constraints, success criteria.
  </Step>
  <Step title="Proposal">
    Scope, timeline, team, pricing, assumptions, risks.
  </Step>
  <Step title="Agreement">
    MSA + SOW (standard terms, no lock-in, IP ownership to client).
  </Step>
  <Step title="Kickoff">
    Team intro, access provisioning, communication cadence, success metrics.
  </Step>
  <Step title="Delivery">
    Iterative delivery, weekly syncs, demo reviews, knowledge transfer.
  </Step>
  <Step title="Closure">
    Final deliverables, runbooks, retrospective, feedback.
  </Step>
</Steps>
