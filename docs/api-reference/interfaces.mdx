Interfaces are the named data shapes used as parameters and return values
across the APIs. This page is the index; the defining API page documents each
interface in its context.

**Introduced:** 1.0 · **Status:** Stable

## Conventions

- Field names use `lowerCamelCase`.
- **Required** fields are always present. **Optional** fields may be omitted
  and are typed `T | undefined`.
- Unknown fields are rejected by the runtime with `ERR_INVALID_ARGUMENT`;
  interfaces are closed by default.
- Dates are epoch milliseconds (`number`), never ISO strings, except in JSON
  documents and schemas where ISO 8601 is used.

## Example: `MessageEnvelope`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `from` | `string` | yes | Sender package identifier. |
| `to` | `string` | yes | Recipient package identifier. |
| `id` | `string` | yes | Message identifier. |
| `type` | `string` | yes | Message discriminator. |
| `message` | `unknown` | yes | JSON-serializable payload. |
| `timestamp` | `number` | yes | Epoch milliseconds. |
| `reply` | `(payload) => Promise<void>` | no | Reply callback, when request/response. |

## Example: `Page<T>`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `items` | `T[]` | yes | Page items. |
| `cursor` | `string \| undefined` | no | Pass to the next call for the next page. |
| `hasMore` | `boolean` | yes | Whether more items exist. |

```ts
const page = await app.storage.list({prefix: 'settings', limit: 50});
while (page.hasMore) {
  // process page.items
  const next = await app.storage.list({prefix: 'settings', limit: 50, cursor: page.cursor});
}
```
