Every facade method in the platform follows the same conventions described on
this page. This is the master index; each entry links to the defining API page
for full detail.

**Introduced:** 1.0 · **Status:** Stable

## Signature conventions

- All methods return a `Promise` and reject on failure — none throw
  synchronously.
- Optional parameters are trailing and typed `T | undefined`.
- Object parameters use closed interfaces (see [Interfaces](/docs/api-reference/interfaces)).
- Failures reject with an `OrivonError` carrying a stable `code`
  (see [Error Codes](/docs/api-reference/error-codes)).
