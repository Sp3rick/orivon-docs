Every byte that crosses the network does so through one service. This draft
defines the network service, its transports and its adapters.

## Summary

The network service owns all sockets. It speaks classic HTTP over TLS, the
modern HTTP variants, and peer to peer transports with NAT traversal, plus
adapters for blockchain RPC. The reference design is the
[Networking Stack](/docs/technical-design/networking-stack) page.

## Purpose

Centralizing networking makes it possible to apply privacy, integrity and
policy in one place. A single service means no component talks to the network
untracked, and every connection can be owned, pooled and governed uniformly.

## Implementation status

The reference implementation includes the network service with socket
ownership, transport adapters and pooling. The draft tracks the design at
0.1.0. No conformance suite has been published yet.
