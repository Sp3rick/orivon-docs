Data outlives code, so storage is where integrity and durability matter most.
This draft defines the storage engine, content addressing and synchronization.

## Summary

Storage combines a content addressed blob store, a metadata database and a key
store. Data is identity scoped and encrypted, and durable data is
distinguished from reconstructible data. The reference design is the
[Storage Engine](/docs/technical-design/storage-engine) page.

## Purpose

Storage must be safe from substitution, safe from loss, and portable across
devices. Content addressing gives integrity by construction; identity scoped
encryption gives privacy; synchronization gives continuity.

## Implementation status

The reference implementation includes content addressing, the metadata store
and synchronization with conflict handling. The draft tracks the design at
0.1.0. No conformance suite has been published yet.
