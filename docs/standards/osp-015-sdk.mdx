The SDK is the surface that turns specifications into software people can
write. This draft defines its scope, its bindings and its integration points.

## Summary

The SDK packages the public interfaces of the ecosystem (module API, wallet
API, event system, configuration) into libraries developers can build against.
The concept is described in the [SDK](/docs/ecosystem/sdk) ecosystem page.

## Purpose

Implementing the ecosystem interfaces by hand is error prone. The SDK exists
so that developers build against tested, typed wrappers of the specifications,
and so that the ecosystem grows because the friction of entry is low.
