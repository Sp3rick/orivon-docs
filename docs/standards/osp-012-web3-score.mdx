The Web3 Score is Orivon's reputation concept for sites, identities and
applications. This draft defines the score format and how it is computed.

## Summary

The Web3 Score is a structured reputation record with a defined format, a
defined computation over on-chain and behavioral signals, and a path to
verifiability. The concept is described in the
[Web3 Score](/docs/ecosystem/web3-score) ecosystem page.

## Purpose

Users need a trustworthy signal about what they are interacting with. The score
exists to make reputation a data format instead of an unverifiable claim, so
that sites, identities and applications can be compared on transparent terms.

## Implementation status

The Web3 Score is at the concept stage. The draft defines the intended format
and computation, and the reference implementation has not yet shipped a
complete scorer. This is reflected in the draft status and in the
[Future Products](/docs/ecosystem/future-products) ecosystem page.

<Callout type="warning" title="Concept in progress">
  The Web3 Score is an evolving product concept. This draft records the current
  direction, not a shipped feature. Expect the format and computation to change
  during discussion.
</Callout>

## Future work

- A defined computation with a verifiable output.
- An open scoring committee to review signals.
- Standardized score verification for third parties.
