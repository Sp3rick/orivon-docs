Use this template when filing a bug report. Copy it into your issue and fill
in every section. See [Bug Reports](/docs/contributors/bug-reports) for the
guidance on writing each part well.

```markdown
### Summary
One sentence describing the bug.

### Environment
- OS:
- Runtime version:
- SDK version:
- Browser version (if relevant):

### Steps to reproduce
1.
2.
3.

### Expected behavior
What you expected to happen.

### Actual behavior
What actually happened, including the full error output.

### Minimal reproduction
Attach the smallest module or project that reproduces the bug, or describe
it precisely enough to rebuild.

### Additional context
Anything else that helps: frequency, workarounds, related issues.
```

<Callout type="info" title="A reproduction beats everything">
  The reproduction is the most valuable part of the report. If you can write
  a failing test, include it; it is the exact reproduction and becomes the
  regression test.
</Callout>
