Recognition is how the community thanks its builders. Orivon acknowledges
contributors through public credit, release notes, community highlights and
the rewards program. This page explains how it works.

<Callout type="success" title="Credit is a promise">
  If your work is merged, your credit is public. Recognition is not a
  perk; it is the community honoring the deal that makes open source work.
</Callout>

## Release notes

Significant contributions appear in the release notes of each release:

| Contribution | In the notes |
| --- | --- |
| Feature | Under "Added", with your name |
| Fix | Under "Fixed", with your name |
| Docs and design | Acknowledged in the notes |
| Security finding | Credited in the advisory |

See [Release Process](/docs/contributors/release-process) for how notes are
generated.

## Community highlights

The community celebrates standout work:

- Contributors of the period are highlighted in community channels.
- Significant milestones are announced and celebrated.
- Case studies share how contributors built something valuable.

<Callout type="info" title="Highlights are about the work">
  Highlights celebrate what the work enabled, not a popularity contest.
  Any contribution that moved the project meaningfully can be highlighted.
</Callout>

## Special recognition

Some contributions deserve more than a mention:

| Category | Recognition |
| --- | --- |
| Critical security findings | Named credit in the advisory |
| Long term maintainership | Maintainer status and leadership roles |
| Program leadership | Recognition in the governance model |
| Exceptional impact | The rewards program and DAO |

## The rewards program

The DAO and rewards program recognize high impact work:

<Accordion title="How does the rewards program work?">
  The program, defined by the [governance](/docs/ecosystem/governance) model,
  distributes rewards for high impact contributions. The specifics evolve
  with the DAO; recognition is the constant.
</Accordion>

<Accordion title="Is all work rewarded?">
  No. Most work is volunteered, which is what keeps the project
  independent. Rewards target specific high impact work, and public credit
  applies to all merged contributions.
</Accordion>
