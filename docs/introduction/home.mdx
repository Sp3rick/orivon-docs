## Welcome to Orivon

Orivon is a **browser for the next generation of the web**: a trustless, user-friendly
Web3 browsing system built on new open standards. This documentation is the definitive
reference for what Orivon is, why it exists, and how it is built.

Whether you are a visitor, developer, contributor, investor or researcher, this is the
right place to begin.

## Mission

> To bring Web3 to actual mass adoption by making the browser itself the interface to a
> trustless internet.

Today, using decentralized technology means juggling wallets, bridges, extensions and a
dozen trust assumptions. Orivon treats Web3 capabilities as **first-class browser
features**. They are safe by default, invisible when they should be, and open to everyone.

## Vision

Long-term, Orivon changes how software is distributed and how computing is organized:

- **Applications become websites.** Software is delivered, updated and run through the browser.
- **Identity, data and value stay with users.** They do not sit with a handful of platforms.
- **The ecosystem is modular and open.** It is built on public standards anyone can implement.

## A quick tour of the stack

The architecture is deliberately simple. Applications sit on top of a browser powered by a
runtime and a core, all grounded in open standards.
