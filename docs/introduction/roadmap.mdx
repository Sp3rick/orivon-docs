Orivon is built in phases. Each phase delivers a foundation for the next, so that later
levels plug into the architecture without redesigning it. This roadmap reflects where the
project is today and where it is heading.

## Current progress

Orivon is in its **foundations** phase: the concept is defined, the information
architecture is live, and the open specifications that everything else depends on are
being written.

## How to read this roadmap

- **Completed** milestones have shipped, like this documentation.
- **In progress** milestones are being worked on right now.
- **Planned** milestones are defined but not yet started.

The roadmap is community-facing and will evolve. Detailed, lower-level planning lives in
the [Vision](/docs/introduction/vision) and [Key Features](/docs/introduction/key-features)
pages, and progress is announced in the community channels.

<Callout type="info" title="Want to shape the roadmap?">
  Orivon is community-driven. Join the discussion in the community channels or open an
  issue on GitHub to propose changes.
</Callout>
