The ecosystem is the collection of projects built on Orivon: applications,
modules, tools, and services that extend the platform. This page introduces
the categories and the path to getting listed.

## Project categories

<CardGrid columns={3}>
  <Card title="Applications" to="/docs/community/project-directory#applications">
    End-user apps: browsers, wallets, social, productivity, games.
  </Card>
  <Card title="Modules" to="/docs/community/project-directory#modules">
    Runtime modules: capabilities, protocols, algorithms, utilities.
  </Card>
  <Card title="Developer Tools" to="/docs/community/project-directory#developer-tools">
    CLI, scaffolding, testing, debugging, profiling, CI/CD.
  </Card>
  <Card title="Infrastructure" to="/docs/community/project-directory#infrastructure">
    Nodes, relays, indexers, oracles, bridges, hosting.
  </Card>
  <Card title="Identity & Privacy" to="/docs/community/project-directory#identity-privacy">
    DID methods, verifiable credentials, private compute, ZK tools.
  </Card>
  <Card title="Research & Standards" to="/docs/community/project-directory#research-standards">
    Implementations of standards, reference clients, test suites.
  </Card>
</CardGrid>

## Quality criteria

To be listed in the directory, a project should:

<CheckList
  items={[
    'Build on Orivon (runtime, browser, SDK, or standards).',
    'Be open source (Apache 2.0 or compatible).',
    'Have a public repository with readable documentation.',
    'Follow Orivon conventions (capabilities, module format, naming).',
    'Have a maintainer reachable for security coordination.',
  ]}
/>

## Getting listed

<Steps>
  <Step title="Build it">
    Create your project on Orivon. Use the [SDK](/docs/api-reference/overview)
    and follow the [Developer Documentation](/docs/developers/overview).
  </Step>
  <Step title="Document it">
    Write a clear README, usage guide, and contribution guide.
  </Step>
  <Step title="Submit">
    Open a PR to the ecosystem directory (To Be Announced) with your project
    metadata.
  </Step>
  <Step title="Review">
    The Ecosystem Working Group reviews for quality criteria.
  </Step>
  <Step title="Publish">
    Approved projects are added to the directory and announced.
  </Step>
</Steps>
