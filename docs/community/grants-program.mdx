The Grants Program funds work that grows the Orivon ecosystem: infrastructure,
research, tooling, education, and community programs. It is open to anyone —
individuals, teams, and organizations.

## Program overview

| Aspect | Detail |
| --- | --- |
| **Cycles** | Quarterly (4 per year) |
| **Budget per cycle** | To Be Announced (target: $100k+/cycle) |
| **Grant sizes** | Micro: up to $5k · Standard: $5k–$25k · Large: $25k–$100k |
| **Eligibility** | Anyone, anywhere. No affiliation required. |
| **IP** | Grantees retain IP. Deliverables must be open source (Apache 2.0 or compatible). |
| **Reporting** | Monthly check-ins, final report, public demo. |

## Application process

<Steps>
  <Step title="Read the RFP">
    Each cycle publishes a Request for Proposals with focus areas and
    priorities. Read it first.
  </Step>
  <Step title="Draft a proposal">
    Use the grant proposal template: problem, approach, milestones, budget,
    team, and success metrics.
  </Step>
  <Step title="Submit">
    Submit via the grants portal (To Be Announced) before the deadline.
  </Step>
  <Step title="Review">
    The Grants Committee (community members, maintainers, ecosystem partners)
    reviews all proposals.
  </Step>
  <Step title="Decision">
    Decisions announced within 4 weeks. Feedback provided to all applicants.
  </Step>
  <Step title="Execute">
    Funded grantees sign a simple grant agreement and begin work.
  </Step>
</Steps>

## Review criteria

| Criterion | Weight |
| --- | --- |
| **Ecosystem impact** — advances the platform or community | 30% |
| **Technical feasibility** — realistic plan, qualified team | 25% |
| **Openness** — deliverables open source, reusable | 20% |
| **Sustainability** — plan for maintenance after grant | 15% |
| **Diversity** — team, region, or approach underrepresented | 10% |

## Grant lifecycle

| Phase | Duration | Expectations |
| --- | --- | --- |
| **Kickoff** | Week 1 | Align on milestones, set up repo, introduce to mentors. |
| **Execution** | 8–24 weeks | Monthly check-ins, public progress updates. |
| **Midterm review** | Midpoint | Demo progress, adjust scope if needed. |
| **Completion** | End | Final demo, report, code published, blog post. |
| **Post-grant** | Ongoing | Maintenance plan active; eligible for follow-on grants. |
