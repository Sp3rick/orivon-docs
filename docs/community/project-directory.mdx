The Project Directory is the searchable catalog of all ecosystem projects
listed on Orivon. It is the go-to place for users to find apps, for developers
to find modules, and for contributors to find projects to join.

## Project cards

Each project in the directory shows:

| Field | Description |
| --- | --- |
| **Name** | Project name and logo. |
| **Category** | Primary category (see above). |
| **Tags** | Technology tags: `wasm`, `rust`, `typescript`, `p2p`, `zk`, etc. |
| **Description** | One-line summary. |
| **License** | Must be Apache 2.0 or compatible. |
| **Repository** | Link to public repo. |
| **Website** | Project homepage (if any). |
| **Maintainer** | Contact for security and collaboration. |
| **Status** | `Active`, `Maintenance`, `Archived`, `Experimental`. |
| **Orivon version** | Minimum compatible platform version. |
| **Last updated** | Timestamp of last release or commit. |

## Search and filters

The directory supports:

- **Text search** across name, description, and tags.
- **Category filter** (single or multiple).
- **Tag filter** (AND/OR logic).
- **Status filter** (active, maintenance, etc.).
- **Sort** by: recently updated, stars, name, category.

## Submitting a project

See [Ecosystem Projects](/docs/community/ecosystem-projects#getting-listed) for the
submission process. In short:

1. Build on Orivon.
2. Open source it (Apache 2.0 compatible).
3. Document it.
4. Submit via PR to the directory repo.
5. Get reviewed and published.

## Directory data

The directory is maintained as a structured data file (YAML/JSON) in the
ecosystem repository. This enables:

- Programmatic access for tooling.
- Automated freshness checks (stale detection).
- Integration with the [Grants Program](/docs/community/grants-program) and
  [Community Showcase](/docs/community/community-showcase).

## API access

A public API for the directory is planned (To Be Announced) to enable:

- IDE plugins for module discovery.
- Dashboard integrations.
- Automated dependency tracking.
