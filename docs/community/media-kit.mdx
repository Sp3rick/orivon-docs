## About Orivon (boilerplate)

> **Orivon** is an open-source browser and platform that returns control of the
> web to its users. Built on WebAssembly, capability-based security, and open
> standards, Orivon enables user-owned identity, private data, and a
> programmable web where participants are rewarded for the value they create.
> The project is governed by its community under the Apache License 2.0.

- Your deadline.
- Any specific assets or access you need.
