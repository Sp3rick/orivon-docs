Community events are where the community meets in real time: to learn,
collaborate, and build relationships that sustain the project.

## Event types

| Type | Cadence | Audience | Format |
| --- | --- | --- | --- |
| **Community Summit** | Annual | All contributors | Hybrid (in-person + stream) |
| **Workshop Series** | Monthly | Developers, researchers | Virtual, hands-on |
| **Office Hours** | Bi-weekly | Anyone with questions | Virtual, drop-in |
| **Regional Meetups** | Monthly per region | Local community | In-person |
| **Hackathons** | Quarterly | Builders | Hybrid, themed |

See [Meetups](/docs/community/meetups) and [Hackathons](/docs/community/hackathons)
for details on those programs.

## Hosting an event

The community supports member-hosted events through the
[Community Working Group](/docs/community/working-groups/community):

<CheckList
  items={[
    'Speaker bureau: experienced speakers for your event.',
    'Swag kits: stickers, shirts, and swag for meetups.',
    'Stipends: modest budget support for venue/food (application required).',
    'Promotion: event listed on calendar, newsletter, and social channels.',
    'Recording: help recording and publishing virtual events.',

To request support, open an issue in the community repo with the `event-support` label.

## Code of conduct at events

All official and supported events follow the [Code of Conduct](/docs/contributors/code-of-conduct).
Organizers are expected to:

- Publish the Code of Conduct on the event page.
- Designate a safety contact for the event.
- Report incidents to the Community Working Group.

<Callout type="success" title="Events are for everyone">
  If you need accommodations (captioning, accessibility, dietary, scheduling)
  to participate, let the organizers know. We want you there.
</Callout>
