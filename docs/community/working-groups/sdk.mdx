The **SDK working group** coordinates the developer experience for building on
Orivon: the SDKs, tooling, templates, and libraries that make the platform
accessible.

## Mission

Make building on Orivon as natural as writing for any mainstream platform —
with first-class types, clear docs, and tools that prevent common mistakes.

## Scope

<CheckList
  items={[
    'SDK design, APIs, and ergonomics.',
    'Developer tooling: CLI, build tools, debugging.',
    'Templates, starters, and example projects.',
    'Type definitions and IDE integration.',
    'Coordination with Developer Experience and Documentation groups.',
  ]}
/>

## Typical work

- Designing and reviewing SDK APIs (see the [API Reference](/docs/api-reference/overview)).
- Building and maintaining the CLI and scaffolding tools.
- Publishing and maintaining example projects for the
  [Developer Documentation](/docs/developers/overview).
- Improving type safety and IDE hints for capability-based permissions.
