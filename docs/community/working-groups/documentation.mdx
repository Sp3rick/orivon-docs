The **Documentation working group** coordinates all project documentation: the
docs site, contributor guides, standards documentation, and research library.

## Mission

Make the platform learnable, the standards citable, and the contribution path
obvious — so that anyone can go from zero to productive without guessing.

## Scope

<CheckList
  items={[

    'Research library and whitepaper publishing.',
    'Coordination with SDK, Developer Experience, and Community groups.',
  ]}
/>

## Typical work

- Maintaining the docs site (this site) and its search index.
- Writing and reviewing [Contributor Guides](/docs/contributors/overview).
- Publishing and versioning [Standards](/docs/standards/overview).
- Curating the [Whitepapers & Research](/docs/research/overview) library.
