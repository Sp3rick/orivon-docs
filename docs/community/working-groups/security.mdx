The **Security working group** coordinates the project's security posture:
threat modeling, auditing, vulnerability handling, and the responsible
disclosure process.

## Mission

Protect the ecosystem and its users through proactive security engineering and
transparent, fair incident handling.

## Scope

<CheckList
  items={[
    'Threat modeling for new features and architecture changes.',
    'Security audit coordination and tracking.',
    'The responsible disclosure process and response playbook.',
    'Cryptographic choices and key management practices.',
    'Coordination with the Runtime, Core, and Ecosystem teams.',
  ]}
/>

## Typical work

- Running threat model reviews for new modules and standards (see
  [Security Model](/docs/ecosystem/security-model)).
- Coordinating third-party audits and publishing results.
- Managing the disclosure process (see
  [Responsible Disclosure](/docs/contributors/responsible-disclosure)).
- Maintaining security checklists for contributors.
