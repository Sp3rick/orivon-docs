The **Browser working group** coordinates everything users touch: the browser
user interface, rendering behavior, and platform integration.

## Mission

Deliver a browser that is fast, private, and delightful — and that makes the
ecosystem's capabilities visible to users without exposing them to risk.

## Scope

<CheckList
  items={[
    'Browser user interface and interaction design.',
    'Rendering pipeline behavior and performance.',
    'Integration of privacy and capability features into the UI.',
    'Platform integration: operating systems, notifications, media.',
    'Accessibility and internationalization of the browser.',
  ]}
/>

## Typical work

- Designing privacy-preserving UI patterns (permissions, identity, Web3 Score).
- Improving page load performance and responsiveness.
- Coordinating the rendering pipeline (see
  [Rendering Pipeline](/docs/research/rendering-pipeline)).
- Reviewing browser architecture decisions (see
  [Browser Architecture](/docs/research/browser-architecture)).
