The **Core working group** coordinates the platform's shared foundation: the
architecture decisions, stability guarantees, and concerns that span multiple
subsystems.

## Mission

Keep the platform coherent, stable, and evolvable — so that changes in one
subsystem don't silently break another.

## Scope

<CheckList
  items={[
    'Cross-cutting architecture decisions and trade-offs.',
    'Platform stability and compatibility guarantees.',
    'Shared infrastructure: logging, metrics, configuration.',
    'Dependency management and supply chain security.',
    'Coordination with all other working groups.',
  ]}
/>

## Typical work

- Maintaining the architecture overview (see
  [Technical Design Overview](/docs/technical-design/architecture-overview)).
- Defining compatibility and deprecation policies.
- Coordinating large refactors that touch multiple repositories.
- Managing the platform's dependency and security update cadence.
