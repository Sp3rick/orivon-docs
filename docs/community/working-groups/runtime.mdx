The **Runtime working group** coordinates the execution engine at the heart of
Orivon: the runtime that loads modules, enforces capabilities, and executes
WebAssembly.

## Mission

Make the runtime fast, secure, and predictable — the foundation every other
layer builds on.

## Scope

<CheckList
  items={[
    'Execution engine architecture and performance.',
    'WebAssembly integration and module execution.',
    'Capability enforcement and sandboxing behavior.',
    'Runtime stability, observability, and error handling.',
    'Coordination with the Security and Core working groups.',
  ]}
/>

## Typical work

- Benchmarking and profiling the execution pipeline.
- Improving module startup time and memory usage.
- Hardening the sandbox against escape attempts.
- Maintaining runtime design documents (see
  [Runtime Architecture](/docs/research/runtime-architecture)).

<Card to="/docs/research/runtime-architecture">
