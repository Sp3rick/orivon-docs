The **Developer Experience working group** coordinates the experience of
building on Orivon: from the first `npm create orivon` to debugging a
production module.

## Mission

Make every developer interaction with the platform fast, predictable, and
confidence-building — so that building on Orivon feels like a superpower, not
a chore.

## Scope

<CheckList
  items={[

    'Coordination with SDK, Documentation, and Browser groups.',
  ]}

## Typical work

- Auditing the [Getting Started](/docs/developers/getting-started) flow.
- Improving CLI output, error messages, and debug tooling.
- Building and maintaining the [Project Templates](/docs/developers/creating-your-first-project).
- Coordinating release communication and migration guides.
