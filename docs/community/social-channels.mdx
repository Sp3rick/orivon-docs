The official Orivon social channels. Follow for announcements, releases,
community highlights, and technical content.

## Official channels

| Platform | Handle | Purpose | Frequency |
| --- | --- | --- | --- |
| **GitHub** | [github.com/orivon](https://github.com/orivon) | Source, issues, releases, discussions | Daily |
| **Discord** | [discord.gg/orivon](https://discord.gg/orivon) | Real-time chat, support, community | Continuous |
| **Forum** | [forum.orivon.dev](https://forum.orivon.dev) | Long-form discussion, RFCs, governance | Daily |
| **Twitter/X** | [@orivon](https://x.com/orivon) | Announcements, highlights, threads | Daily |
| **Mastodon** | [@orivon@fosstodon.org](https://fosstodon.org/@orivon) | Decentralized announcements | Daily |
| **LinkedIn** | [Orivon](https://linkedin.com/company/orivon) | Professional updates, hiring, partnerships | Weekly |
| **YouTube** | [Orivon](https://youtube.com/@orivon) | Talks, workshops, demos, office hours | Weekly |
| **Blog** | [blog.orivon.dev](https://blog.orivon.dev) | Long-form announcements, deep dives | Bi-weekly |
| **Newsletter** | [newsletter.orivon.dev](https://newsletter.orivon.dev) | Curated monthly digest | Monthly |

<Callout type="info" title="Verify before you trust">
  Only the channels listed above are official. Orivon team members will never
  DM you asking for tokens, keys, or payments. Report impersonators to
  security@orivon.dev.
</Callout>

## Channel purposes

| Channel | Best for |
| --- | --- |
| **GitHub** | Issues, PRs, release notes, code discussion. |
| **Discord** | Quick questions, live collaboration, community hangout. |
| **Forum** | RFCs, design discussions, governance, deep technical threads. |
| **Twitter/X** | Real-time announcements, thread-format technical content. |
| **Mastodon** | Same as Twitter, on decentralized infrastructure. |
| **LinkedIn** | Professional updates, hiring, partner announcements. |
| **YouTube** | Recorded talks, tutorials, office hours, demos. |
| **Blog** | Long-form: architecture, research, governance, case studies. |
| **Newsletter** | Curated summary: releases, community, events, grants. |

## Community-run channels

The community runs additional channels that are **not official** but are
valuable:

| Channel | Platform | Run by |
| --- | --- | --- |
| **Orivon Developers** | Discord | Community WG |
| **Orivon Research** | Discord | Research WG |
| **Regional Discords** | Discord | Meetup organizers |
| **Language-specific** | Various | Translation teams |

These channels follow the [Code of Conduct](/docs/contributors/code-of-conduct)
and are listed in the [Community](/docs/community/community) page.

## How to engage

| Action | Where |
| --- | --- |
| **Report a bug** | GitHub Issues |
| **Request a feature** | GitHub Discussions / Forum |
| **Ask a quick question** | Discord #questions |
| **Discuss a design** | Forum (RFC category) |
| **Share your project** | Forum (Showcase) / Discord #showcase |
| **Find a mentor** | Discord #mentorship / Forum |
| **Organize an event** | Forum (Events) / Community WG |
| **Give feedback** | Any channel — we read all of them |
