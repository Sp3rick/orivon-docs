The Brand Guidelines ensure Orivon looks and sounds consistent across every
touchpoint. They are for the community, partners, press, and anyone
representing the project.

## Logo

### Primary logo

The primary logo is the **Orivon wordmark + symbol**. It exists in:

- **Full color** (on light backgrounds)
- **White** (on dark/colored backgrounds)
- **Black** (for single-color print)

### Logo variations

| Variation | Use case |
| --- | --- |
| **Wordmark only** | Tight horizontal spaces |
| **Symbol only** | App icons, favicons, small spaces |
| **Stacked** | Vertical layouts, square formats |

### Clear space

Maintain clear space equal to the height of the "O" in the wordmark on all
sides. No other elements may intrude.

### Minimum size

| Format | Minimum width |
| --- | --- |
| Digital | 24px (symbol), 120px (wordmark) |
| Print | 10mm (symbol), 50mm (wordmark) |

## Colors

### Primary palette

| Color | Hex | RGB | Use |
| --- | --- | --- | --- |
| **Orivon Blue** | `#0066FF` | 0, 102, 255 | Primary actions, links, focus |
| **Deep Navy** | `#0A0F1A` | 10, 15, 26 | Backgrounds, text, primary UI |
| **Pure White** | `#FFFFFF` | 255, 255, 255 | Text on dark, backgrounds |

### Secondary palette

| Color | Hex | RGB | Use |
| --- | --- | --- | --- |
| **Electric Cyan** | `#00D4FF` | 0, 212, 255 | Accents, highlights, code |
| **Signal Green** | `#00E676` | 0, 230, 118 | Success, positive signals |
| **Warning Amber** | `#FFB300` | 255, 179, 0 | Warnings, attention |
| **Alert Red** | `#FF3D00` | 255, 61, 0 | Errors, critical actions |

### Neutral palette

| Color | Hex | Use |
| --- | --- | --- |
| **Gray 900** | `#111827` | Body text (light mode) |
| **Gray 700** | `#374151` | Secondary text |
| **Gray 400** | `#9CA3AF` | Borders, dividers |
| **Gray 100** | `#F3F4F6` | Light backgrounds |

### Accessibility

All color combinations meet **WCAG AA** contrast ratios for text and UI
elements. Use the provided combinations; do not invent new pairings.

## Typography

### Primary typeface: **Inter**

Inter is used for all UI, headings, body text, and code (monospace variant).

| Style | Weight | Use |
| --- | --- | --- |
| **Inter Display** | 600–700 | Headlines, hero text |
| **Inter** | 400–500 | Body text, UI labels |
| **Inter Mono** | 400–500 | Code, technical labels |

### Type scale

| Element | Size | Weight | Line height |
| --- | --- | --- | --- |
| H1 | 48px / 3rem | 700 | 1.1 |
| H2 | 36px / 2.25rem | 600 | 1.2 |
| H3 | 28px / 1.75rem | 600 | 1.3 |
| H4 | 22px / 1.375rem | 600 | 1.4 |
| Body | 16px / 1rem | 400 | 1.6 |
| Small | 14px / 0.875rem | 400 | 1.5 |
| Code | 14px / 0.875rem | 400 | 1.5 |

## Voice and tone

### Voice attributes

| Attribute | Description |
| --- | --- |
| **Clear** | Simple words, short sentences, no jargon without definition. |
| **Confident** | We know what we are building and why. No hedging. |
| **Inclusive** | "You," "we," "the community." Not "the user" or "the developer." |
| **Honest** | We acknowledge trade-offs, risks, and what is not yet built. |

### Tone by context

| Context | Tone |
| --- | --- |
| **Documentation** | Instructional, precise, encouraging. |
| **Blog/Announcements** | Celebratory, transparent, forward-looking. |
| **Social media** | Conversational, community-focused, visual. |
| **Security/Incidents** | Calm, factual, action-oriented. |
| **Governance** | Neutral, procedural, respectful. |

## Iconography

Icons use the **Lucide** icon set (consistent with the docs site). Use outlined
style, 2px stroke weight. Do not mix icon sets.

## Photography and imagery

- **Style:** Clean, technical, human-centered.
- **Subjects:** Real contributors, workspaces, code, hardware.
- **Avoid:** Generic stock photos, abstract "tech" backgrounds, crypto clichés.

## Co-branding

For partner co-branding (events, integrations, joint announcements):

- Orivon logo on left, partner logo on right.
- Equal visual weight (same height).
- Minimum 2x clear space between logos.
- Use partner's approved logo only.
